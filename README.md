# Cardiovascular Risk Analysis

This project aims to analyze patient data and predict the likelihood of high cardiovascular risk based on demographic, lifestyle, and clinical features. It combines data cleaning, visualization, and machine learning to provide actionable insights for healthcare analysis.

## Project Overview
The workflow of this project includes:

1. **Data Collection**: Patient datasets were sourced from Kaggle.
2. **Data Cleaning & Preprocessing**: Raw data was cleaned and structured using Excel and Python to handle missing values and format inconsistencies.
3. **Data Visualization**: Power BI was used to explore patterns, disease prevalence, and trends across age, gender, and ethnicity.
4. **Predictive Modeling**: Machine learning models were built in Python to classify patients into high or low cardiovascular risk groups.

## How to Run
The patient dataset used in this project can be downloaded from Kaggle [here](https://www.kaggle.com/datasets/tarekmuhammed/patients-data-for-medical-field).
